Керування сайтом

Зміни зберігаються прямо в репозиторій сайту на GitHub і з'являються на linasmusicgroup.org приблизно за 1–2 хвилини.

Як отримати ключ (один раз, 2 хвилини)
  1. Відкрийте github.com/settings/personal-access-tokens/new (увійдіть у свій GitHub).
  2. Token name: наприклад «Адмінка сайту». Expiration: на ваш вибір (наприклад, 1 рік).
  3. Repository access → Only select repositories → виберіть linas-studio.
  4. Permissions → Repository permissions → Contents → Read and write.
  5. Натисніть Generate token, скопіюйте ключ і вставте його сюди.

Ключ зберігається лише в цьому браузері. Нікому його не пересилайте.
